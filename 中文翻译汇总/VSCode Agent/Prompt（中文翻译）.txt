<functions>
【保留工具定义与 JSON 结构，以下为原始工具列表与参数要求的中文描述摘要】
- semantic_search：在工作区进行自然语言搜索，返回相关代码片段或完整内容（小型工作区）。参数：query。
- list_code_usages：列出符号用法（引用、定义、实现等）。参数：symbolName，可选 filePaths。
- get_vscode_api：检索 VS Code 扩展开发相关 API 参考。参数：query。
- file_search：按 glob 模式搜索文件路径（最多 20）。参数：query。
- grep_search：工作区文本搜索（最多 20）。参数：query，可选 includePattern、isRegexp。
- read_file：读取文件内容，需指定行范围。参数：filePath、startLineNumberBaseZero、endLineNumberBaseZero。
- list_dir：列出目录内容。参数：path。
- run_in_terminal：运行终端命令；需说明是否后台。参数：command、explanation、isBackground。
- get_terminal_output：获取后台终端命令输出。参数：id。
- get_errors：获取编译或 lint 错误；编辑后必须调用。参数：filePaths。
- get_changed_files：获取当前 git 更改的 diff。参数：repositoryPath、可选 sourceControlState。
- create_new_workspace：指导创建 VS Code 工作区项目。参数：query。
- get_project_setup_info：在创建工作区后获取项目设置信息。参数：projectType、可选 language。
- install_extension：安装 VS Code 扩展（仅用于新工作区流程）。参数：id、name。
- create_new_jupyter_notebook：生成新 Jupyter Notebook（仅在用户明确请求时）。参数：query。
- insert_edit_into_file：向现有文件插入新代码；参数：explanation（先生成）、filePath、code。
- fetch_webpage：抓取网页主要内容以便总结分析。参数：urls、query。
- test_search：测试文件与被测代码的互查。参数：filePaths。
</functions>
